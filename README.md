# RIDE

MVP publik aplikasi mobilitas / ride-hailing dengan UX mobile-first yang terinspirasi pola super-app transportasi Indonesia, menggunakan brand dan implementasi original **RIDE**.

## Live

https://ride-two-mu.vercel.app

## Fitur MVP

- RIDE Motor, RIDE Car, dan RIDE Send
- Peta interaktif OpenStreetMap + Leaflet
- Geolokasi browser untuk titik jemput
- Pilih tujuan dengan klik pada peta
- Estimasi jarak, waktu, dan tarif
- Pilihan tier Hemat / Prioritas / Comfort
- Simulasi pencarian dan pencocokan driver
- Riwayat pesanan demo via localStorage
- Responsive desktop + mobile
- Installable PWA + service worker app shell

## Status

Frontend MVP sudah live. Pencarian driver, wallet, pembayaran, akun, Food, Mart, dispatch armada, chat, tracking real-time, dan transaksi nyata masih membutuhkan backend produksi serta integrasi penyedia layanan.

## Source

Static web app tanpa build step: `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`.
